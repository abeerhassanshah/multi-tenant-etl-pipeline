
# Student Records Project

A beginner-friendly Python program that collects and displays student records.

## Features

- Validates full names, ages, marks, and roll numbers.
- Supports roll numbers such as 06-24, B34F, and 12.
- Prevents duplicate roll numbers.
- Stores student records in a dictionary.

## Project structure

- `students_records/main.py`: starts the program.
- `students_records/helpers.py`: contains validation and record functions.
- `.gitignore`: excludes temporary Python files.

## Requirements

Python 3.10 or newer.

## Run the program

From the project root, run:

`python students_records/main.py`

## Design principles

- SSOT: validation limits are defined once.
- KISS: each file and function has a clear job.
